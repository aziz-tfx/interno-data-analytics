ПРАКТИКА · SQL

Объединяем две таблицы и считаем продажи по городам.

query.sql
SELECT c.city, COUNT(o.id) AS orders, SUM(o.amount) AS totalFROM orders oJOIN clients c ON c.id = o.client_idGROUP BY c.cityORDER BY total DESCLIMIT 5;

ПРАКТИКА · POWER BI / DAX

Одна DAX-мера — и динамика роста по месяцам оживает в дашборде.

measure.dax
Sales Growth % =VAR Current = [Total Sales]VAR Prev = CALCULATE( [Total Sales], DATEADD('Date'[Date], -1, MONTH))RETURN DIVIDE(Current - Prev, Prev)
