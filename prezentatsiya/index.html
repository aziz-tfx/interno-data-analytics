AMALIYOT · SQL

Ikki jadvalni birlashtirib, shaharlar bo'yicha savdoni hisoblaymiz.

query.sql
SELECT c.shahar, COUNT(o.id) AS buyurtmalar, SUM(o.summa) AS jami_savdoFROM buyurtmalar oJOIN mijozlar c ON c.id = o.mijoz_idGROUP BY c.shaharORDER BY jami_savdo DESCLIMIT 5;
