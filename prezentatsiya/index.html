SQL — JONLI SO'ROV

Ikki jadvalni birlashtirib, shaharlar bo'yicha savdoni hisoblaymiz.

query.sql
SELECT c.shahar, COUNT(o.id) AS buyurtmalar, SUM(o.summa) AS jami_savdoFROM buyurtmalar oJOIN mijozlar c ON c.id = o.mijoz_idWHERE o.sana >= '2025-01-01'GROUP BY c.shaharORDER BY jami_savdo DESCLIMIT 5;

measure.dax
Savdo O'sishi % =VAR Joriy = [Jami Savdo]VAR Otgan = CALCULATE( [Jami Savdo], DATEADD('Sana'[Date], -1, MONTH))RETURN DIVIDE(Joriy - Otgan, Otgan)
